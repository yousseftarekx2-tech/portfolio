I'm Youssef, a Computer Science student at Al Nahda University with a clear focus: becoming an excellent Flutter developer. Most of what I know, I've learned by shipping real projects instead of just following tutorials — turning Figma designs into working screens, wiring up state management, and structuring apps so they don't fall apart as they grow.

I care about clean, layered architecture: separating UI from business logic and data handling, using patterns like the repository pattern instead of stuffing logic into widgets. My current flagship project, TaskFlow, is being built exactly that way — UI first, then real data and state management layered on top without a rewrite.

Outside of Flutter, I'm comfortable in C++, Python and JavaScript, and I'm actively learning Firebase to round out my mobile toolkit. Long-term, I'm working toward backend development with Node.js and MongoDB, so I can eventually build complete apps end-to-end.
